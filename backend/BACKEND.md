# バックエンド設計・セットアップ手順（GAS ＋ Googleスプレッドシート）

申込フォーム → データ保存 → 自動返信メール（QR付き）→ LPにサンクス表示、までを無料・サーバー不要で構築します。

## 全体の流れ
```
LPフォーム送信
   │  fetch POST (JSON / text-plain)
   ▼
Google Apps Script (Webアプリ)   ← backend/vibes-gas.gs
   ├─ ① スプレッドシートに1行保存
   ├─ ② シリアル番号を発番（VJ8-XXXXXX）
   ├─ ③ QRコード画像URLを生成
   ├─ ④ 申込者へ自動返信メール（QR埋め込み）
   └─ ⑤ { ok, serial, qrUrl } を返却
   ▼
LP：サンクスモーダルにQR・シリアルを表示
```

## セットアップ（所要10〜15分）

### 1. スプレッドシートを用意
1. [Googleスプレッドシート](https://sheets.new) を新規作成（名前例：`バイブスジャパンvol.8_申込`）
2. URLの `/d/` と `/edit` の間の文字列（＝**スプレッドシートID**）を控える
   例：`https://docs.google.com/spreadsheets/d/`**`1AbC...xyz`**`/edit`
   ※ヘッダー行は初回送信時に自動作成されます（手動作成不要）

### 2. Apps Script にコードを貼り付け
1. スプレッドシートのメニュー **拡張機能 → Apps Script** を開く
2. 既定の `コード.gs` の中身を全部消し、`backend/vibes-gas.gs` の内容を丸ごと貼り付け
3. 先頭の `CONFIG` を編集：
   - `SHEET_ID` … 手順1で控えたID（同じスプレッドシート内で動かすなら空でもOK）
   - `MAIL_FROM_NAME` … 送信者名（例：バイブスジャパン運営事務局）
   - `CC_TO_ORGANIZER` … 申込通知を受け取りたい運営メール（不要なら空のまま）
4. 保存（💾）

### 3. Webアプリとしてデプロイ
1. 右上 **デプロイ → 新しいデプロイ**
2. 種類の選択（⚙️）→ **ウェブアプリ**
3. 設定：
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. **デプロイ** をクリック
5. 初回は権限承認を求められます → 自分のGoogleアカウントで許可
   （「このアプリは確認されていません」→ 詳細 → 安全でないページに移動、で進めます。自作スクリプトのため問題ありません）
6. 発行された **ウェブアプリのURL**（`https://script.google.com/macros/s/……/exec`）をコピー

### 4. LPに接続
`js/script.js` の先頭：
```js
var ENDPOINT_URL = 'ここにコピーしたURLを貼り付け';
```
保存して完了。フォーム送信すると、スプレッドシートに行が増え、申込者に自動返信メールが届きます。

### 5. テスト
1. LPの申込フォームからテスト送信
2. スプレッドシートに1行増えるか確認
3. 入力したメールアドレスに、QR付きの確認メールが届くか確認
4. サンクス画面にQR・シリアルが表示されるか確認

## 補足・運用メモ

- **CORSについて**：LP側は `Content-Type: text/plain` で送信し、GASのプリフライト失敗を回避しています（コード設定済み）。
- **QRコードの生成元**：現在は無料の外部サービス `api.qrserver.com` を利用（エンコード内容はシリアル番号のみ＝個人情報は含みません）。Google製に寄せたい／自社ホスティングしたい場合は、GAS内でQRを生成しDrive/Cloud Storageに保存する方式にも変更できます。
- **当日の受付**：スプレッドシートの「当日ステータス」列でチェックイン管理できます。QRリーダーでシリアルを読み、行を検索して「入場済」に更新する運用が簡単です（希望あれば受付用の簡易チェックインもGASで作成可）。
- **メール到達性**：GmailApp送信は1日あたりの送信上限があります（無料アカウントで約100通/日、Workspaceで約1,500通/日）。700名規模なら **Google Workspace アカウントでの運用を推奨**。上限が心配な場合はSendGrid等の外部メール送信への切替も可能です。
- **重複申込対策**：現状は許容。メール重複を弾きたい場合は実装追加できます。

## 🎫 当日の受付チェックインツール（QRスキャン対応）

受付スタッフがスマホ/タブレットで開き、QRを読む（または手入力）と、その場でスプレッドシートの「当日ステータス」を「入場済」に更新できます。入場済/総申込のカウントも表示します。

### 追加セットアップ
1. Apps Scriptエディタで **＋（ファイルを追加）→ HTML** を選び、ファイル名を **`checkin`** にする（拡張子 `.html` は自動）
2. `backend/checkin.html` の中身を丸ごと貼り付けて保存
3. `vibes-gas.gs` の `CONFIG.CHECKIN_KEY` を**推測されにくい合言葉**に変更（例：`vibes8-uketsuke-9f3k`）
4. **再デプロイ**：デプロイ → デプロイを管理 → ✏️ → バージョン「新バージョン」→ デプロイ
   （コードを変えたら毎回この再デプロイが必要です）

### 使い方（当日）
受付端末のブラウザで次のURLを開く（`exec` のURL＋パラメータ）：
```
https://script.google.com/macros/s/……/exec?page=checkin&key=（設定した合言葉）
```
- 「📷 カメラでQRを読み取る」→ 申込者のQRをかざす → 氏名確認 → 「入場させる」
- QRが読めない時は `VJ8-XXXXXX` を手入力して「照会」
- 既に入場済みの人は⚠️表示（二重入場を防止）

> スタッフ端末では、このURLをホーム画面に追加しておくとアプリのように使えます。合言葉入りURLは関係者のみに共有してください。

## データ項目（スプレッドシート列）
| 列 | 内容 |
|---|---|
| 受付日時 | 送信タイムスタンプ |
| シリアル番号 | VJ8-XXXXXX（入場QRの値） |
| 氏名 / フリガナ | 入力値 |
| 大学・学校名 / 学部 / 学科 / 学年 | 入力値（それぞれ別列・すべて必須） |
| メール / 電話 | 入力値（電話は先頭0保持のため文字列書式） |
| 参加目的 | 複数選択を「 / 」区切りで保存 |
| フォーム種別 | quick（FV直下）/ main（最下部） |
| 当日ステータス | 既定「未入場」→ 受付で「入場済」に更新 |
| 入場時刻 | チェックイン時に自動記録（受付ツール使用時） |
